# Build a Blog with MyST Markdown

Building a blog with MyST Markdown is a great way to share your thoughts and ideas with the world. It is also a great way to learn more about MyST Markdown and how to use it to build your own website.

## What You Will Need

- A [GitHub](https://github.com) account (free).
- For local preview and customization: a code editor like [VS Code](https://code.visualstudio.com) or [Cursor](https://cursor.com), [Node.js](https://nodejs.org) (version 18 or later), and Python 3.
